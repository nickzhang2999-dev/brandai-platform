## 已确认的反馈

### 1. 足球 / 草地样例：背景补全失败

用户截图依次展示原图、草地背景层、足球主体层。背景层中原足球位置仍有球形的平滑绿色补丁，草叶纹理与周边不连续；足球投影仍留在草地上。主体层周围可见零散残点，边缘待检查原始 RGBA 后确认。截图黑底不能单独证明真实 alpha 或黑底已写入素材。

验收目标：隐藏或移走足球后，草地仍自然连续，看不出主体轮廓；补全区不应以模糊涂抹代替纹理。主体投影必须明确归属，不能移动足球后在背景留下孤立的原投影。

### 2. “隐藏部分不可恢复”属于过度概括

用户明确要求按被遮挡内容判断。应区分：原图缺少可直接读取的像素、可以合理推断补全、可以确认准确的原始内容。不得把三者混为一谈，也不得把能力提示当作背景修复失败的免责理由。

拟采用分类：

| 内容 | 处理与验收方向 |
|---|---|
| 草地、天空、墙面等纹理 / 背景 | 允许基于上下文合理补全；检查纹理、光照、接缝与主体残影 |
| 白线、砖缝、重复图案等规则结构 | 结合走向、透视与重复规律延续；检查连续性 |
| 人体、复杂商品结构等身份 / 几何敏感内容 | 推测有风险，按任务决定补参考、保持组合或限制操作 |
| 文字、Logo、精确产品信息 | 无依据不得将生成内容宣称为准确恢复，优先原素材 / 参考 |

以上是本项目建议策略，不是已经实现的分类器或 Lovart 已公开的算法。

## 明天的建议执行顺序（待继续，不自动实施）

1. 收齐用户其他反馈，沿用足球样例作首个固定回归案例；保留原图、每层原始 RGBA 和现有任务结果，避免反复盲调用。
2. 检查真实层 alpha、足球边缘残点、背景补丁范围及投影归属，区分分割失败、背景补全失败、显示问题。
3. 设计遮挡判断结果：内容类别、前后遮挡关系、可推断程度、精确信息保护与投影策略。低风险纹理尽量默认顺畅处理；仅真实歧义才向用户澄清，不照搬动态海报每次确认的交互。
4. 评估主体提取与背景补全分开的路径，以及当前已配置模型是否支持对应输入。先核对官方 API 参数和成本，再选择实现；现有 Fal 分层接口不假设接受未公开的蒙版参数，也不假设多写一句提示词就能控制各输出层。
5. 对允许补全的区域采用受限的局部修复，保护未遮挡区域；决定影子跟随主体、独立层或保留环境阴影的条件。足球样例的纯背景需去掉主体及其关联投影。
6. 增加“独立层可用性”验收：隐藏 / 移动主体检查背景；在浅色、深色和棋盘格上检查边缘、alpha 与杂点；规则线条检查延续。现有整体重合对比仍保留，但不能单独证明遮挡区修好了，因为放回主体会遮住坏补丁。
7. 局部失败优先局部返工，不能未经授权自动重复整图付费调用；保留原任务、费用和素材来源记录。
8. 按实际能力改提示：自然背景说明上下文补全；结构敏感区域提示推测；精确信息缺参考时说明缺口。取消笼统的不可恢复结论。

## 首例通过标准

- 足球隐藏 / 位移后：背景没有球形残影、明显纹理模糊块或孤立的球影。
- 足球单层：透明区域无明显杂点，边缘无明显草地粘连或黑边。
- 未修复区：原有白线、纹理、构图和色调不发生无关改变。
- 原位合成：主体位置、比例与光照保持合理；“合成相似”与“独立可编辑”分别报告。
- 没有参考的隐藏内容只称合理补全，不称准确恢复。
