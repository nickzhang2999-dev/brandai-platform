# 2026-11-05 · 画布输入框“更多”展开区修复

## 问题与原因

用户截图中，“同时准备 PSD”和“素材用途与输出画框”被压成右侧竖条。
操作栏强制 flex-nowrap，原生 details 又使用 display:contents，浏览器的 details 内容包装参与了横向挤压。360px 侧栏扣除内边距后，设置区实际只有约78px；仅改换行仍只有168px，不能完整解决。

## 修改

- OwnedConversationPanel：紧凑操作按钮允许换行，“更多”改为具有 aria-expanded、aria-controls 的按钮。
- 设置区直接占操作栏下方完整一行，关闭时使用 hidden；不依赖原生 details 的匿名包装盒。
- PSD 分层方式、层数允许合理换行；打开素材与画框工具会收起设置，草稿参数保留。
- 对话、完整画布、自动 PSD 与预览 UI 验证脚本同步新的开闭语义。
- 不调整模型、生成接口、计费、发布策略和 main 配置。
