# 设计灵感导航与首页文案切换修复

用户反馈：进入设计灵感后出现旧菜单；首页点击“文案创作”无反应或切换异常。

## 原因与修改

灵感页原来位于 `(brandai)` 路由组，自动套用了旧导航。现保持 `/inspiration` URL，将页面移至独立 Studio 目的页，只提供返回当前品牌工作台的链接。沿用 Studio 会话和成员权限检查，显式无效品牌不回退；搜索、会话、收藏和反馈接口不变。

首页模式脚本在新会话中正常，远端两个 JS 归一化换行后与部署源一致。可复现的失灵场景是已有未完成交接记录时模式按钮被原生 disabled，以及 IndexedDB 保存失败后模式回退缺少就近说明；不能据此断言已读取用户浏览器的具体故障状态。

模式栏现在说明锁定原因。安全可结束的交接提供“保留原项目并切换文案/图片”，复用既有恢复逻辑，保留原需求与图片；已提交但回执未知的任务仅提供“继续原项目”，不生成新的请求身份或重复调用模型。存储失败明确显示原模式保留。中文输入法 blur 清理已存在，本次未重复修改。

## 验证口径

- 独立灵感页权限回归 11 项，覆盖登录回跳、品牌参数、无权访问、停用账号和成员权限变更。
- 本地生产构建真实浏览器验证旧侧栏消失、品牌返回链接、筛选刷新、手机布局、Studio 模式切换与导航往返、无权品牌不回退。
- 首页协议 47 项；原 8 个视口布局检查增加旧交接恢复、未知回执保护及存储失败 3 个浏览器场景，随镜像 CI 执行。
- Web 1909、contracts 312、UI 39、AI 664；typecheck、生产 build、导出校验、发布合同均通过。本轮交互检查没有付费模型调用，不代表生成质量验收。

提交、远端 CI 和开发预览版本以本轮实际部署回执为准；不发布正式主站，不改变数据库和供应商配置。

## 同日追加：模式按钮样式与旧缓存

用户截图显示图标贴文字、按钮变矮和直角焦点框。实际开发预览的 `home-start-studio.css` 字节与 bb4d2f7 源码一致，但公网响应为 `Cache-Control: max-age=14400, must-revalidate`，覆盖了应用的 `no-store`。HTML 固定地址没有把资源内容变化反映到请求 URL。

真实 Chromium 对照中，替换为引入模式选择器之前的旧 CSS 后，按钮由 flex / 44px / 999px 圆角 / 8px 间距退化为 inline-block / 23px / 0 圆角 / 0 间距，复现截图。没有读取用户浏览器缓存，不能断言其具体缓存版本。

导出器现在为 HTML 中的本地样式与脚本，以及 CSS 内的本地依赖添加 `novart_sha256` 内容版本。依赖先计算、父资源后计算，叶子样式变化会传导到入口 URL；原有查询参数和片段保留，外部地址与页面导航不改。manifest 对最终导出字节计数及校验，源码保持原设计。

验收补充真实浏览器计算样式与旧缓存升级：保留一份仍新鲜的旧固定地址 CSS，再加载新版导出，必须请求内容版本地址并恢复胶囊按钮。原测试只检查按钮未超出屏幕，未检查其实际样式，这一缺口已补入布局回归。

本地验证：导出器 8 项；布局 11 项（另含旧缓存正反对照和键盘焦点）；真实登录生产构建在 1440/390 两个宽度下切换两种模式及刷新，全部样式请求带版本且 200。全量 Web 1909、contracts 312、UI 39、AI 664、typecheck、build、发布合同 7+6 项通过。本轮没有模型调用，远端版本和同提交 CI 另以部署回执核对。
