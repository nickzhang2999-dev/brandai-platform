# 2026-10-22 首页图片 / 文案入口分离

## 需求与范围

用户要求首页设置合适区域，将生图和文案创作分开。沿用现有首页、项目和原生画布，不新增独立产品页。本轮在 `claude/canvas-copywriting` 工作区本地开发；不推送、不修改 main、不改线上配置、不执行数据库迁移。

## 实现

1. 现有输入框上方新增圆角「图片创作 / 文案创作」切换，选中态使用产品紫色，支持键盘焦点和 aria-pressed。
2. 切换输入提示、快捷示例、字数限制与主按钮；原输入和附件不清空，超限不截断。
3. 文案模式的主按钮为「进入文案创作」。先通过已有接口保存项目和原始需求，附件走原有可恢复上传/画布保存，随后打开文案面板、带入需求并选中附图。
4. 首页文案入口不会发起生图或文案付费请求。用户进入面板后点击「生成文案」才调用现有持久任务接口。
5. 创作类型写入品牌作用域的首页恢复记录；提交后锁定模式。模式保存期间阻止创建，写失败回滚，旧记录默认按图片逻辑恢复。
6. 文案面板先持久化交接草稿再确认接收；同一 requestId 不重复覆盖用户修改。草稿以用户/品牌/项目隔离，编辑后刷新恢复；实际生成任务与原始项目需求仍由服务端权威保存。
