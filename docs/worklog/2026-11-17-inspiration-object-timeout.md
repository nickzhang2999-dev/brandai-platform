# 灵感库图片接收超时修复

## 线上问题

Omni 第 336 版发布及独立验签成功；DeepFlare 一次接收任务于 11 月 16 日 19:01:25（北京时间）失败。相同时间 worker 记录 object / timeout / attempts=3 / HTTP 200。旧 992 个案例保留，新版未激活。日志没有对象 SHA，不能断言失败对象就是验收大图，也不能由 HTTP 200 推断正文下载完成。

## 修改

基于 layer 运行提交 `371e88a96ba73f781a9502be77b2f2e77e17cd75` 的隔离分支 `fix/receiver-object-progress-timeout`。

仅调整 `publisher-fetch.ts` 的图片对象读取：响应头最多等待 15 秒；正文每收到非空字节重置 15 秒停滞计时；每次读取总上限 120 秒。空数据不能续命。正文读取显式响应取消，错误响应清理不阻塞退出。其他阶段保留 15 秒总期限。

保留同一固定对象最多三次只读重试、上层取消、响应大小限制、哈希与签名校验。没有修改业务接收协议、配额、模型接口、账号或生产配置，没有重新提交失败任务。
