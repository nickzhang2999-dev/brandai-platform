## 最少配置与正确入口

管理员页面为 **`/admin/settings`**；读取接口为 `GET /api/admin/settings/ai`，保存接口是 **`PUT /api/admin/settings/ai`**。旧说明若写为 POST 或把 `/admin/settings/ai` 当页面，需按实际路由理解。该接口经过 `requireAdmin()`，项目普通成员不自动拥有平台配置权限。

1. 生图/整图修改验收：实际 provider、模型标识、授权 API key，以及供应商要求的 base URL。不能把默认模型字符串或非空 key 当作能力验收。
2. 图片持久化验收：独立 bucket、限定该 bucket 的访问凭据、endpoint、region、forcePathStyle；按供应商及既有实现需要设置稳定的 URL 基址。新画布通过授权同源 Asset raw 路由取图，不要求开放公共桶。
3. 品牌视觉检查验收：另外配置真实 VLM 的 provider/model/key/base URL。layer provider 只在本轮实际验收图层分解时才需要，不是文字生图与整图修改的必需项。
4. Web 与 Worker 必须继续使用一致且稳定的设置加密材料；已有加密 clean base 的密钥轮换需要受控迁移，不能随意换值。

配置语义以 `apps/web/src/lib/settings.ts` 为准：AI 为 DB → env → 默认；存储值虽有 env 兜底，但 `configured` 有意要求管理员明确保存 DB 字段，防止默认占位 MinIO 被误当可用服务。不要仅新增 `S3_*` 后修改共享默认来让检测变绿。
