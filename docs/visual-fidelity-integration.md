# 主体与品牌保真集成

本轮作用域为 `claude/layer-quality` 分层预览。设计规则见 [visual-fidelity-guard](skills/visual-fidelity-guard/SKILL.md)。这个可复用文档随产品版本保存；实际执行依靠下述 worker 和契约，不会在运行时读取个人电脑的 Skill 文件。

## 实际流程

1. Studio worker 在最终用户要求、实际应用品牌规则、参考素材和编辑来源确定后，生成确定性约束清单和输入摘要。完整原文覆盖检查之外，按分句增加要求子项，编辑保留的颜色、身份、轮廓、标志、文字、数量、区域独立检查。不新增规划模型调用。
2. Studio 普通生成实际带入主体保真指令，含 direct 路径；专用抠图/蒙版修复沿原工具接口。只有提示词约束时，不声称执行了像素保护或分割。
3. 成品归档后，复用已有一次品牌视觉检查，同时发送实际成品、经工作区/项目授权的编辑源和本次实际参与的参考图。检查文件摘要、来源权限及总字节预算；原参考不是重新选择的当前品牌图片。风格参考不自动升级为身份锁定。
4. 服务端根据冻结的完整清单重新汇总模型证据。输出/输入摘要不符、漏项、重复、无对象定位或仅整图色板证据不能通过。有效硬失败仍报告失败；其他硬项未知报告待核验。软偏好不冒充硬要求。
5. 结果绑定当前任务 attempt、归档图、品牌快照和保真快照；调用前和发布时再验来源。来源不可用只让保真待核验，有效品牌结果仍保留。历史没有保真快照不补造成功记录。
6. UI 独立显示主体与品牌保真及逐项依据，旧品牌 PASS 不能替代主体核验。待核验可由用户明确再检查；不会自动重复收费调用或重新生成图片。

## 边界

- 分句和规则编译不是完美语义解析。模型必须对复合条件给完整证据，不能核实则未知；未经真实用例评测不能宣称能阻止所有“绿苹果变红”。
- 契约限制为最多64条检查、单字段4000字符；超过限制保存明确不可核验原因，生成本身仍可完成，不截断后声称全检。
- 原参考最多8张，另可带1张编辑源；成品、禁用规范示例及保真来源总计不超过32MB。任一必要来源缺失、变更或撤权均不能声称已比对。
- 此次没有自动新增分割器、OCR、蒙版生成器、像素合成保护或自动收费修复。新视角和遮挡补全仍属于生成推断。
- 已保存资料、已启用规则、规则已实际发送、实际图片通过视觉核验分别展示；品牌草稿不会被自动启用。
- 模型审核不是人工审核，不触发灵感发布或替换原文件。公司共享库开关及权限是独立流程。

## 共享库准备与启用

管理员正常入口 `/admin`，候选初始化页 `/admin/inspiration`。`INSPIRATION_SHARED_SETUP_LIBRARY_ID` 只用于准备；普通用户仍沿用原私有品牌库。管理员明确选定品牌所属公司后初始化，再通过正常 CDS 部署启用 `INSPIRATION_SHARED_LIBRARY_ID`。公司范围按 owner 隔离，跨品牌不等于跨所有账户公开。

实际开放还需正常管理员初始化、Omni 发布目标与签名范围一致、接收成功及两个同公司品牌读取验收。仅页面、测试或开关存在均不代表共享库已开放。
