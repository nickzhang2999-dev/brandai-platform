# Novart 自研画布接入计划｜2026-10-10

用户决定改用公司自研画布，继续在产品整合分支开发。

## 第一批

产品 `/canvas` 改为独立 React 自研编辑器，继续嵌入已评审工作台。复用公司 OpenCanvas 交互、现有权限/文档/素材/生成接口，不加载 tldraw 或模板编辑器。支持图片、文字、基本图形、自由笔迹、选择拖动与缩放、平移缩放、撤销重做、保存恢复及 PNG/SVG 导出。生成与上传使用真实回执，配置缺失准确报错。

## 文档兼容

通过纯数据适配器读取现有 SHAKKERDATA gzip JSON，保留原始未知字段与对象；继续使用已有 novart-native-v1 存储、revision、mutationId 和权限接口，不运行旧 SDK。这是存储兼容。

运行时文档结构为 items、camera、pageId、source、warnings。元素字段为 id、kind(image/shape/text/stroke/frame)、x/y/w/h、rotation、opacity、可选填色/描边/文字/字号/笔迹点/持久图片URL。新增图片映射 c-image 兼容记录，已有素材用途和生成几何接口可继续识别。旧对象不能可靠转换时保留记录、明确提醒并阻止覆盖。

## 并行分工

1. 模型、文档编解码、旧对象保护与导出。
2. 编辑组件、指针交互、工具栏与编辑历史。
3. 产品客户端、真实文档会话、上传与生成回执。
4. 主任务负责页面路由、集成审核、独立浏览器验证、门禁和日志。

## 验收

不加载第三方编辑器；混合内容编辑后可撤销、保存、重开、导出；旧未知内容不丢失。合成接口交互与真实 DB/S3/provider 验收分别记录。首次完整产品仍需真实外部配置。用户 main 和共享数据保留；本批不启动目标模式、Docker或用户浏览器控制。

## 当前检查点

- 已实现并跑通本机实际 Chromium 的 23 项交互：基本对象/自由笔迹、变换/历史、保存恢复、整幅 PNG/SVG、手机布局、首页带图及交接幂等、只读/冲突/恢复失败保护。
- 首页带图和归档接线仅替换产品导出的脚本，不改独立评审捕获文件。
- 后端数据结构、身份、素材与生成任务服务继续复用；完整真实 DB/S3/provider 验收未完成。
- 未完成：EXACT 素材用途/输出框、改图入口、需求草稿恢复、复杂旧文档兼容、通知深链与大画布图片虚拟化。依赖这些能力的旧设置保留并明确阻断提交。
- 需求归因 N + R：用户选择替换引擎，将现有业务接到可自行维护的画布；第一批不宣称完整功能等价或已上线。
