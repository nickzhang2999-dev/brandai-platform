# Novart 自动准备可编辑 PSD

2026-10-13。开发分支：`devUpdate1012`。当前实施记录，最终验收结果见当日开发日志。

## 用户流程

在生成面板勾选“同时准备可编辑PSD”，选择 2–10 层后提交生成。原图先完成生成和持久化，后台继续分层；关闭页面不取消任务。结果卡分别显示原图和 PSD 准备状态，完成后可下载 PSD 或将图层展开到画布。失败保留原图，读取进度不会自动再次调用模型。

该选择属于一次生成请求的服务端记录。项目重新打开时恢复最新已提交的选择；尚未提交的开关变更不代表新的后台任务。普通生成未选 PSD 时不增加分层调用。

当前 PSD 编码预算为每进程 256 MiB，同时只执行一个导出，导出期限 30 秒。按真实像素画幅与层数核算，约 2K 方图支持两层，四层超限；自动流程会在分层模型调用前拒绝超预算任务并保留原图。页面提前提示限制，不暗中降低尺寸或减少层数。其他长宽比例按真实面积核算，不能只凭“2K”标签保证可导出。

## 复用边界

- 现有生图请求、BullMQ Worker、生成结果归档、项目素材、租户权限与任务恢复继续使用。
- 现有 Studio 分层任务及加密图层存储承担模型调用和结果持久化。自动任务只接受已校验的本项目生成素材；手动画布分层仍保留原先的文档版本与来源校验。
- PSD 编写复用项目现有 `ag-psd`，每张 RGBA 图像写为独立像素图层，保留完整原图画幅、透明通道和叠放顺序，并写入合成预览。
- Qwen 官方开源项目已提供图片分层和 PSD 示例。当前产品已有 Fal/Qwen 分层适配；这轮不下载大模型或启动本机 GPU 服务。模型配置和真实分层质量验收另记，不以文件格式测试代替。

## 后台契约

- `StudioGenerationInput.psdLayerCount`：可选 2–10；未携带表示普通生成。
- `StudioGenerationView.psdLayerCount`：从不可变请求上下文恢复，无选择或历史任务返回 null。
- GET `/api/workspaces/{workspaceId}/studio/generated-psd?projectId={projectId}&requestId={generationRequestId}`：只读任务状态，包含项目与请求身份、是否请求、状态、错误、已发布分层回执及安全下载路径。
- GET `/api/workspaces/{workspaceId}/studio/decomposition/{requestId}/export?projectId={projectId}&format=psd`：经过身份与项目成员校验，只读取已成功发布的完整持久图层，生成实际 PSD 二进制。

所有长任务使用服务端队列。模型调用使用稳定请求身份与单次 claim；归档重试不重新生图或分层。权限撤销、严格保留素材、配置缺失、超时与队列故障需明确处理。原图完成状态与 PSD 失败状态分离。

## 文件范围和验收

PSD 是本次分层产物，包含可分别移动、隐藏和编辑的栅格图层。图片中的文字不会自动恢复为可编辑文字或矢量。画布后续的排列修改与原始分层结果是不同版本，当前任务下载不宣称包含未保存的画布改动。

文件检查必须实际写出并重新读取 PSD，验证签名、尺寸、层数、层名、透明通道、层序与合成像素。前端交互检查使用实际 React 页面和 Chromium；隔离 fixture 只证明交互，不宣称真实 AI 成功。独立数据库 HTTP 验收验证身份、作用域、失败保护与模型零调用边界。

真实 AI 验收需要可用分层模型配置和持久存储，按小规模授权单独执行：真实生成 → 自动分层 → 持久图层 → 下载 PSD → 编辑展开 → 保存重开。尚未执行的环节不得标记完成。
