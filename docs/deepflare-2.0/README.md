## 已有能力与尚未接通

本批提供真实服务端工作单 CRUD 子集（创建、读取、操作），版本比较、创意方向确认、幂等重试、审计快照和事务内待执行记录。支持「先看方向」和「直接制作」两种工作单路径。默认关闭，只有明确允许的品牌可访问接口。

**这是骨架，不是可交付的完整 AI 团队。** `READY` 表示“已确认，等待执行器接入”；返回值固定 `executionAvailable: false`。尚无新产品 UI、粗构图渲染、真实角色执行器、最终稿审核、记忆提炼或 Ommi 网络接入。不能将合同测试、草图或待执行记录作为真出图验收证据。
