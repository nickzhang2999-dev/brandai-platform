# 完整画布的被动交付计时

在独立预览中正常使用完整画布，然后从 Web、Worker、Python AI 服务取同一时间窗的日志。运行以下命令汇总。

```sh
python scripts/summarize-studio-delivery.py web.log worker.log ai.log > delivery.json
```

按生成请求号关联点击、生成 Worker 领取、发送到 AI、供应商 HTTP 请求及响应、归档任务入队及领取、成品入库和画布显示。三类服务分别使用 DF_STUDIO_DELIVERY_TRACE=1 开启或 0 关闭。默认在服务收到 review/p0-canvas-recovery 分支名或对应队列前缀时开启。其他模型适配器需单独核实。

浏览器在页面前台、资源加载、图片与画布可见范围相交时记录显示。刷新、关闭页面、未滚动到该位置以及上报失败均可能留下缺项。资源接收完成时间由浏览器提供，部分样本缺失。点击到可见用同页面单调时钟。点击到 Worker 领取跨时钟，仅为近似。供应商请求耗时包含传输及对方排队或处理。

先统计缺项与覆盖率，再按场景比较完整样本。保留失败、超时及结果未知的请求。脚本仅读日志。
