# Sol 海报预览交付记录

完整编辑器使用当前项目中的商品图。设计师可以在「项目内容 → 素材」把一张素材标成「视觉风格」，保存项目资料，再在「对话改图 → Sol 海报简报」中选中它。确认后，第一张输入图提供商品，第二张输入图提供构图和用光参考。

预览采用后台已配置的文本模型。每次修改读取服务器保存的简报记录、已确认的受众、商品和品牌资料。本地 DSH 配置仍走已有的会话执行器。确认时核对资料版本和参考图，重复确认沿用同一生图回执。

本地验证通过了带参考、失效参考、越项目引用、单次确认、契约、类型检查和生产构建。预览真实模型验收单独记录。试点授权限同一账号最多三次文字简报、一张成图，完成后移除临时模型绑定。
