# Studio 多品牌与紧凑侧栏

## 行为约定 · 2026-10-14

- 普通用户可以新增多个品牌，不按套餐限制品牌数量。既有套餐迁移只将 `Plan.maxWorkspaces` 改为 `-1`；生图额度、价格和权限沿用现有规则。
- Studio 侧栏的当前品牌按钮打开完整品牌列表；只有一个品牌时也保留“新增品牌”。画布或窄屏侧栏显示品牌首字，完整名称在按钮标题、无障碍名称和菜单中可见。
- 新增品牌通过 `/api/workspaces` 创建品牌及 OWNER 成员，事务失败不留下成功回执；明确创建成功后的切换失败只重试选择已有品牌。
- 新增时网络断开、服务端 5xx 或成功回执无法读取，则结果未确认：改为“检查品牌列表”，只读取当前用户的服务端列表，不重复创建，也不按同名品牌猜测归属。明确业务拒绝仍可修正输入后重试。
- Studio 创建请求带稳定的 `X-Novart-Mutation` UUID。服务端在品牌及成员事务内保存 `StudioBrandCreation` 回执；同用户、同请求和相同规范化输入返回同一品牌，防止浏览器传输重发重复创建。相同请求改输入返回 409，品牌删除后的原请求返回 410；同名不同请求仍允许新增。无此头的旧调用保持原有接口语义，不宣称全部历史客户端已具备幂等保护。
- 当前品牌由 `/api/workbench/session` 校验成员并写 cookie，页面 URL 明确包含 `workspaceId`。切换后进入该品牌首页，项目、素材和视觉规范保持品牌作用域。
- 切换前检查正在上传/创建、Studio 未保存设置与品牌草稿，以及打开过的自研画布。画布需确认需求、工作流及文档持久保存；失败、中文组合输入或状态无法确认时保留当前页面。
- 首页附件需等真实 IndexedDB 保存事务确认，首页需求需验证本地暂存写读一致；存储失败时保留内存图片和文本，最多等待 10 秒后给明确出口。已确认存储恢复后可重试切换，未把跨品牌本地缓存当作后端素材归档。
- 窄侧栏隐藏“任务”文本，未读数量超过 9 显示 `9+`，完整数量仍保留在标题和无障碍名称；短窗口导航可滚动，弹窗保持在视口内。

## 验证边界

品牌与布局隔离浏览器检查使用真实生产前端代码和明确的合成 API/iframe 回执，不代表真实数据库、Mac Safari 或 AI 生成验收。真实 HTTP/Auth.js/Prisma 新增与切换验收在一次性 `novart_integration_test` 数据库执行，并分别检验源码服务及构建后的容器。

main 采用从 `2d29125` 建立的专项补丁，仅处理品牌、侧栏与保存保护；开发分支较新的换标、AUTO 分层和 PSD 功能不是此次 main 补丁范围。实际提交、云端检查、迁移及运行版本以当日开发日志为准。
