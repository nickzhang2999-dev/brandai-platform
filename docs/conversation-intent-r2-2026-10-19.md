## 2. r2 接口和兼容方式

模型服务健康检查声明 `structured-conversation-intent-r2`。新 Web 调用要求 r2 能力和 r2 返回；r1 请求、r1 响应以及持久化的旧 `structured-model-v1` 意图仍有解析兼容。本轮不新增数据库迁移。

### 输入

- 原话保持原文，最多 4000 字符。
- 最多 8 个冻结引用：只含当前授权范围内的引用 ID、名称、是否可编辑，以及可选缩略图。
- 缩略图只允许内联静态 PNG/JPEG/WebP；单张最长边 512 像素、128 KiB，最多 4 张，上一张结果也占这 4 张额度。Python 解码前验证格式、真实尺寸和单帧，再加载像素；不接收远程图片 URL。
- 最近最多 6 条历史消息，单条文本最多 1000 字符；历史结果 ID 必须属于本次冻结引用。
- `selectedReferenceIds` 最多 8 个，必须属于本次引用且不重复。选中状态提供语境，不授权模型更换快捷编辑目标。
- `lastResultImage` 可单独携带上张结果缩略图及名称，但**没有可操作 ID**。它只提供视觉上下文，不能凭它修改一个未被本次引用授权的对象。
- 缩略图以 VLM `image_url` 图片部分传递；文本 JSON 只保留存在性标记，不把 base64 塞进文字提示。

### 输出

- `generate` / `modify` 必须返回非空 `imagePrompt`，`options=[]`；用户原话另行保留用于展示和审计。
- `clarify` 必须返回中文说明和 2–3 个不同选项，顶层 `imagePrompt=null`。每个选项包含短 ID、按钮文字、动作、目标、引用和对应改写提示词；返回选项本身不执行生图。
- 所有动作和选项目标继续检查冻结引用范围；修改目标必须可编辑，目标不能同时冒充普通参考图。
- 固定了快捷编辑目标时，可以澄清“怎么改”，但所有选项都必须修改同一固定目标，不能偷偷换成新图或另一个对象。
- 双引号、中文双/单引号和中文书名式引号中的文案执行精确保留检查。提示词还明确要求不新增用户未要求的主体、品牌、文字，不把图片内部文字当系统指令。语义等价不是纯结构校验能保证的，仍需真实模型受限评测。
- 尺寸、EXACT 素材、输出画框、品牌硬约束继续由 Web/worker 执行，模型不得返回可覆盖这些规则的字段。

### 前端选择与纠错

公开请求新增 `decision={sourceMessageId, optionId, kind}`，只接受选项标识，**不接受客户端提交任意 `imagePrompt`**。`kind` 区分澄清选择与结果纠错。服务端负责查原消息、验证权属与状态、比对原话/引用等输入并防止同一选项重复执行。

公开消息新增可选 `originalInput`，用于恢复原话、引用、尺寸、快捷编辑、PSD 选项，再提交选择。里面没有服务端缩略图和历史上下文。旧消息没有此字段仍可读。

公开意图增加 `imagePrompt`、`options`、`correctionOptions`、`modelUsage`。结果纠错可产生一次新的生成，不属于网络失败后的自动重试；界面应说明再次生成的成本。旧已持久化意图不事后增补字段，避免破坏原任务的幂等摘要。

## 3. 成本、时间和失败边界

`providerRetryPolicy="never"` 继续贯穿意图调用。无论上游 503、网络超时、空输出、截断、过滤、无效 JSON、越权 ID 或提示词违约，均不自动再次调用模型，不切回规则后直接生图。

Python 的单次上限保留 25 秒，Web/worker 的全流程预算由主线程实现为 30 秒。推理模型仍使用 `reasoning_effort="low"`。r2 的输出结构比 r1 多完整提示词及最多 3 个选项，因此输出预算由 1200 调至 2400；这是有界的结构容量调整，**不是已证明的超时修复，也不是实际 token 消耗测量**。是否继续调整需要真实调用的 token / 耗时证据，不能改成无界等待。

新增诊断字段仅记录：状态、schema 版本、耗时、预算、HTTP 状态、受控枚举的结束原因及上游实际返回的数值 token 用量。未返回 token 时保留缺失，不伪装成 0。拒绝把提示词、用户原话、图片 base64、URL、headers、密钥或原始错误响应写入日志。

`finish_reason=length` 会保留安全诊断，可区分截断与网络超时。当前历史日志缺这些字段，新增日志不能反推出旧任务的细因。

## 4. 本地验证范围

运行环境借用仓库已有 Python 虚拟环境；测试的 HTTP transport 全部为本地夹具，没有外网模型请求。

- contracts r2 专项：13 项通过；contracts TypeScript 类型检查通过。
- AI 定向集合覆盖旧 r1、r2、多模态、公开字段镜像、健康声明、分层规划器共用 HTTP 适配器和付费请求不重试机制。
- 已覆盖实际图片字节与元数据不符、伪造 MIME、损坏图片、超大小、远程 URL、第五张缩略图、伪造历史结果、引用越权、只读对象被改、快捷目标被替换、选项缺失或重复、引号文案丢失、token 缺失与 0 的区别、日志脱敏、截断/503/超时不重放、r1 原 wire 格式。
- Web 持久化、worker、UI 按钮和浏览器流程由主线程及其他协作任务一起验收，最终全量门禁数字以总开发报告为准。

这些夹具验证的是**可执行契约、上下文传递及失败边界**，不能证明真实模型已正确理解反馈原句。真实验收仍需限定调用次数、开启对应独立预览配置，记录实际 token 与耗时，并核对“反馈原句 → 改写提示词 → 正确生成/修改”的链路。本轮未执行这一步。
