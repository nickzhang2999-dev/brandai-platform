# Nova 灵感库后端接入说明

2026-10-22。本文描述本分支代码；不代表正式站已发布、真实案例已审核或付费模型已验收。

## 启用和连接

功能默认关闭。Web 与 worker 同时设置 `INSPIRATION_ENABLED=true` 后才开放写入和后台任务。
管理员将以下配置保存在服务器私密环境中，不放到浏览器、仓库、API 请求体或发布包内：

- `INSPIRATION_PUBLISHER_URL`：A 端知识发布根路径，例如受信任 HTTPS 地址下的 `/knowledge/v1`。本机 SSH 转发可用 `http://127.0.0.1:<port>/knowledge/v1`；容器内的 localhost 指容器自身，必须先验证真实网络位置。
- `INSPIRATION_READ_TOKEN`：A 端专用只读身份，不使用运维管理员令牌。
- `INSPIRATION_TRUSTED_KEYS_JSON`：`key_id` 到 Ed25519 公钥 PEM 的 JSON 映射。公钥独立交付，不从下载包获取信任。

同步请求由 workspace OWNER 发起，记录持久任务后返回 202。一次成功配置产生本地 workspace 副本，之后每 5 分钟检查更新。独立撤回检查每分钟运行，不等待问答队列；网络失败保留已有撤回集并显示错误。没有配置的工作区不会自动创建内容。HTTP handler 不下载远端文件、不调用模型。

## 本地副本和完整性

Prisma 增量迁移新增 `InspirationState/Release/Record/Image/Chat/Bookmark/Embedding`，均以 workspace 外键隔离，删除工作区时一起删除。图片暂存在 PostgreSQL bytea，适合 20–200 案例试点；扩量前应迁移到现有对象存储并保留同样授权边界。

签名、原始 manifest SHA256、清单文件大小和哈希、图片实际解码、来源和证据引用、审核与展示权限均在激活前校验。完整包和增量包保留不可变记录，事务同时保存图片、案例快照和活动版本。失败保留旧活动版本。相同 case revision 改正文或图片字节均拒绝。完整快照省略案例不会丢失历史修订水位。

撤回水位和累计 case ID 独立于活动版本。回退函数 `rollbackReplica(workspaceId, releaseId)` 只切换已存在本地版本，不降低发布/撤回水位。检索、图片、历史引用和收藏都重新检查当前活动快照及撤回状态。历史引用的修订号变化后展示“已更新或撤回”，不会把原回答配到新图上。

当前试点接收限额：每包 128 MiB、图片 20 MiB/4000 万像素、2000 条记录；一次追溯最多 32 个增量/累计 256 MiB。超限需要人工发布新的完整检查点。JSON 签名 profile 只支持安全整数（含扩展字段），不接受浮点数，必须与 A 发布校验一致。签名排序按 Unicode 码点；验证时不修剪文本。

## 检索和问答

页面 GET 搜索为本地关键词和标签检索，中文长串拆双字补充召回。首版上限 200 个案例，无外部请求。问答后台支持可选文本向量与关键词融合；向量不可用时退回关键词。当前向量缓存按 workspace、端点、模型、维数、预处理版本和文本区分；首次问答可能产生缓存构建开销。它不是已上线的 pgvector 索引，也不能把页面 GET 标为语义检索。

显式配置向量：`INSPIRATION_EMBEDDING_ENDPOINT`、`INSPIRATION_EMBEDDING_MODEL`、`INSPIRATION_EMBEDDING_DIMENSIONS`、`INSPIRATION_EMBEDDING_VERSION`、`INSPIRATION_EMBEDDING_API_KEY`。不推测视觉模型支持向量，不自动复用其他密钥。仅后台 worker 调用，16 条一个有界批次。

问答默认读取 Nova `getEffectiveAiSettings().vlm` 的后台配置（数据库优先），只调用已配置真实 OpenAI 兼容接口。选择 `INSPIRATION_CHAT_PROVIDER=copywriting` 时显式复用新文案功能的 Anthropic Messages 网关配置。两种协议不混用。未配置或失败不会回落到假回答。

外发分析还要求案例、来源、图片各自的 `permissions.analysis` 为 `allowed`。展示授权不自动授权发给模型；未知权限仍可本地浏览，但不会进入向量和模型上下文。普通问答仅收到选定证据文字与必要历史。选图深问由客户端显式提交 selectedImages（caseId、imageId、revision），最多 2 张。worker 只读取当前本地已授权版本，校验哈希后转换为边长不超过 1024、每张不超过 1 MiB 的 JPEG，再按模型协议发送图片内容；不抓取任意图片 URL。发送前后检查撤回与权限，回答区分图像观察和作者事实。

每轮请求必须带 UUID `requestId`，同一用户/工作区重试幂等，复用相同 ID 但不同内容返回冲突。会话仅发起者可读，历史指代按已保存案例顺序和修订解析。模型必须返回每段对应 case/claim ID，引用超出检索证据会失败，不保存为成功。生成前后检查账号仍启用、编辑权限和引用状态。每个 workspace owner 下所有工作区合计每日 UTC 默认 100 次试点问答（INSPIRATION_DAILY_CHAT_LIMIT 可设置 1–10000），防并发超额；记录模型、输入/输出 token 和执行耗时；这只是次数限额，不是正式计费系统。

问答和同步持久化服务器任务，客户端离开仍可继续。问答 6 分钟过期、单 worker 调用最多 4 分钟，无自动付费重试。取消接口持久化终态；worker 每 2 秒检查并尝试中止上游请求（上游已产生的费用不能保证撤销）。灵感页、BrandAI 跨页活动浮层和 Studio 收件箱显示进行中状态、耗时及返回会话入口；终态通知只发给发起者。独立 activity 接口仅提供私有任务元数据，不向旧 Generation 队列混入会话正文。AsyncTask 镜像支持单任务读取。问题正文和回答保存在专用会话表。

收藏按用户和工作区存储，可关联同一工作区项目，保存明确 revision 和批注。同步不覆盖用户收藏/批注。撤回或更新后保留私人批注并将案例标为不可用。当前没有团队共享项目板/批注版本历史/生成用途授权入口。

## 真实验收仍需完成

需要受信任公钥、A 端只读连接、明确审核人与来源授权、20 个真实审核案例，才可进行端到端内容验收。独立测试图只用于隔离数据库和协议测试，不种入产品数据。需要实际模型/向量权限及真实设计任务评测，才可确认回答质量与检索指标。100–200 案例、50 查询评测、备份恢复、容量性能、域间连接及生产发布均须单独记录实测证据。
